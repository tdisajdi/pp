========================================
  Instagram 다운로더 사용방법
========================================

■ 준비물 (처음 한 번만)
  - Windows + Python  https://www.python.org/downloads/
    (설치할 때 "Add python.exe to PATH" 체크)
  - 인스타그램 로그인용 쿠키
      방법 A) Firefox에서 instagram.com 에 로그인 → Firefox 완전 종료
              START.bat 맨 위의 set BROWSER=chrome 을 set BROWSER=firefox 로 변경
      방법 B) 크롬에서 로그인 후 "Get cookies.txt LOCALLY" 확장프로그램으로
              cookies.txt 를 내보내 START.bat 과 같은 폴더에 넣기
      ※ 크롬 쿠키는 "Failed to decrypt cookie" 오류가 나는 경우가 많습니다.

■ 기존 폴더에 덮어쓸 때 (중요)
  - 이 zip에는 following_xxx.txt (목록 파일)이 일부러 들어 있지 않습니다.
    기존 목록(# 제외 표시 포함)을 덮어쓰지 않기 위해서입니다. 기존 파일을 그대로 두세요.
  - 아래 옛 파일은 지우세요: start_gallery_dl.bat, update_following.bat, start.sh
  - instagram_downloads 폴더, gallery_dl_archive.sqlite3, cookies.txt 는 건드리지 마세요.
  - 기본값: BROWSER=firefox, UPDATE_FOLLOWING=0, UPDATE_FROM_SAVED=0
    (새 계정으로 받을 때는 본계정의 팔로잉/저장 게시물을 읽을 수 없으므로 꺼 둠)

■ 사용 순서
  1. START.bat 더블클릭
       → 팔로잉 목록 최신화 (새로 팔로우한 계정만 목록 파일에 추가)
       → 내가 "저장한 게시물"의 작성자 계정도 목록에 추가
         (직접 팔로잉하지 않아도 공개 계정이면 전체 게시물을 받음)
       → 목록의 모든 계정의 게시물 + 릴스 사진 다운로드
       → 중간에 막히면 같은 계정을 잠시 쉬었다가 이어서 받음
  2. 다 받은 뒤, 마지막에 sort_faces.bat 더블클릭 (얼굴 분류)
       → 계정 폴더 안에 single_face / multi_face / no_face 로 나눠짐

■ 저장 위치
  instagram_downloads\instagram\계정아이디\

■ START.bat 설정 (메모장으로 열어 맨 위)
  USE_LOGIN=1           0이면 로그인 없이 다운로드 (내 계정을 전혀 건드리지 않음)
                        → 목록 파일을 그대로 쓰고, 팔로잉/저장 게시물 갱신은 건너뜀
                        → 공개 계정만 가능. 막히기 쉬우니 MAX_ACCOUNTS=5 처럼 소량씩
  BROWSER=chrome        브라우저 (firefox 권장)
  LIST=...txt           팔로잉 목록 파일
  UPDATE_FOLLOWING=1    1=목록 최신화 후 다운로드 / 0=최신화 안 함
  TARGET=...            팔로잉/저장 게시물을 가져올 계정 (쿠키로 로그인한 본인 계정)
  UPDATE_FROM_SAVED=1   1=저장한 게시물의 계정도 목록에 추가 / 0=안 함
  SAVED_RANGE=          비우면 저장 게시물 전체 확인, 1-300 처럼 쓰면 최근 300개만
  MAX_ACCOUNTS=0        0=전체 / 숫자=앞에서 N명만 (처음엔 5 추천)
  DONE_MODE=skip        이미 끝까지 받은 계정: skip=건너뜀 / new=새 글만 확인 / all=전부 다시 확인
  NEW_CHECK=10          new 모드에서 이미 받은 파일이 연속 몇 개 나오면 멈출지
  SLEEP_REQUEST=25-50   인스타 요청 사이 대기(초). 클수록 안전
  BETWEEN_MIN/MAX       계정 하나 끝낼 때마다 쉬는 시간(초), 이 범위에서 무작위
  MAX_RUN=10            한 번 실행에서 실제로 받는 계정 수 상한 (0=무제한)
                        완료된 계정은 세지 않으므로 다시 실행하면 다음 계정부터 이어집니다
  MAX_RETRY=5           한 계정이 막힐 때 이어받기 최대 횟수
  RETRY_WAIT=180       이어받기 전 대기 시간(초)
  MAX_CONSEC_FAIL=3     연속 N개 계정이 실패하면 전체 중단 (로그인 거부 시 계정 보호)

■ 목록에서 제외하고 싶은 계정
  following_xxx.txt 에서 그 줄 앞에 # 을 붙이세요. (최신화해도 유지됨)

■ 끝까지 받은 계정 표시
  - 오류 없이 끝까지 받은 계정 폴더에 숨김 파일 .done 이 생기고, 다음 실행부터 건너뜁니다.
  - 중간에 멈춘 계정은 표시가 없어서 다음 실행 때 이어서 받습니다.
  - 그 계정의 새 글이 궁금하면 DONE_MODE=new 로 바꾸세요. 강제로 다시 보려면 .done 을 삭제.
  - 이전에 받던 계정들은 표시가 없으니, 한 번 더 끝까지 돌고 나면 표시됩니다.

■ Edge만 쓸 수 있을 때
  - START.bat 이 "msedge.exe is still running" 이라고 하면 Edge가 쿠키 파일을 잡고 있는 겁니다.
    작업 관리자에서 msedge.exe 를 모두 종료하거나, 명령 프롬프트에서  taskkill /F /IM msedge.exe
  - 가장 확실한 방법: make_cookies.bat 을 한 번 실행해 cookies.txt 를 만드세요. (확장 프로그램 불필요)
      1) Edge에서 새 계정으로 instagram.com 로그인
      2) F12 → Application(애플리케이션) → Storage → Cookies → https://www.instagram.com
      3) sessionid 행의 Value 를 더블클릭해 복사 (Ctrl+C)
      4) make_cookies.bat 실행 → 붙여넣기(마우스 우클릭) → Enter
    cookies.txt 가 있으면 START.bat 이 그 파일을 쓰고, Edge를 종료하지 않아도 됩니다.
  - sessionid 는 로그인 정보와 같으니 다른 사람에게 보내지 마세요.
    Edge에서 로그아웃하면 그 값은 쓸 수 없게 되니, 받는 동안은 로그아웃하지 마세요.

■ 차단을 피하는 요령
  - 새 계정은 처음 며칠은 평소처럼 앱을 쓰세요 (이메일/전화 인증, 프로필 사진 등).
  - 평소 쓰는 PC, 같은 집 인터넷에서 Firefox로 직접 로그인하세요. VPN은 끄세요.
  - 스크립트가 도는 동안 같은 계정으로 앱이나 웹을 쓰지 마세요.
  - 하루에 한두 번, 한 번에 MAX_RUN 계정씩만. 오류(401, login)가 나면 그날은 멈추세요.
  - 로그인/로그아웃을 반복하지 마세요.

■ 참고
  - 저장한 게시물에서 추가된 계정은 목록 파일 아래쪽 "from saved posts" 구간에 들어갑니다.
    원하지 않는 계정은 그 줄 앞에 # 을 붙이세요.
  - 비공개 계정은 내 계정이 팔로우하고 있어야만 받을 수 있습니다.
  - 이미 받은 게시물은 자동으로 건너뜁니다. 몇 번을 다시 실행해도 됩니다.
  - 동영상 파일은 받지 않고, 릴스/영상 게시물은 대표 이미지로 저장됩니다.
  - 429 오류가 계속되면 휴대폰 핫스팟으로 연결해 보세요.
